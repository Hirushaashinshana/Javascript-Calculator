# Calculator

This is a simple web-based calculator application.

## How to Use

The calculator interface is straightforward:

- **Number Buttons (0-9):** Click these buttons to input numbers.
- **Operator Buttons (+, -, *, /, %):** Click these buttons for mathematical operations.
- **Equals Button (=):** Click this button to see the result of the calculation.
- **Clear Button (Cl):** Click this button to clear the entire input field.
- **Delete Button (Del):** Click this button to remove the last character from the input field.
- **Decimal Button (.):** Click this button to add a decimal point.

## Technologies Used

- **HTML:** For the basic structure of the calculator.
- **CSS:** For styling the calculator.
- **JavaScript:** For the calculator's functionality and logic.
- **Bootstrap:** For additional styling and UI components.

## How to Run

1. Clone this repository or download the files.
2. Open the `index.html` file in your web browser.
